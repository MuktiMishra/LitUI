# LitUI ✨

A beautifully designed, modern **React component library** with a feminine, playful, and vibrant touch. LitUI makes it easy to build stunning UIs with prebuilt components, smooth animations, and interactive effects.

---

## 💜 Features

- **Fully customizable components**: Buttons, cards, navbars, modals, and more  
- **Responsive design**: Looks amazing on desktop and mobile  
- **Smooth hover & click animations**: Make your UI come alive  
- **Socially aware components**: Prebuilt social links with hover effects  
- **Dark & light vibes**: Elegant gradients and glassy effects  
- **Simple integration**: Works seamlessly in any React project
